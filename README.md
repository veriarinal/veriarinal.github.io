# Website Akademik Veri Arinal

Paket ini berisi pembaruan tampilan website GitHub Pages dengan desain akademik modern, responsif, dan satu halaman (one-page).

## Isi paket
- `index.html` — halaman utama dan seluruh bagian profil.
- `assets/css/style.css` — gaya visual dan responsif.
- `assets/js/app.js` — navigasi mobile, tahun otomatis, dan penanda menu aktif.
- `assets/images/README.txt` — petunjuk foto profil.

## Cara memasang di GitHub Pages
1. Unduh dan ekstrak ZIP.
2. Buka repository `veriarinal.github.io`.
3. Unggah/ganti `index.html`, folder `assets/css/`, dan folder `assets/js/`.
4. **Jangan hapus foto profil yang sudah ada.** Pastikan file tetap berada di `assets/images/profile.jpg`.
5. Commit perubahan ke branch yang digunakan GitHub Pages (umumnya `main`).
6. Tunggu proses deployment, lalu buka `https://veriarinal.github.io/` dan tekan `Ctrl + F5`.

## Foto profil
Halaman memanggil foto dari `assets/images/profile.jpg`. Paket ini tidak menyertakan salinan foto pribadi. Pertahankan file foto yang sudah ada di repository. Jika belum ada, unggah foto dengan nama persis `profile.jpg` ke folder `assets/images/`.

## Catatan konten
Bagian publikasi sengaja disiapkan sebagai tempat pengisian data bibliografi terverifikasi. Tambahkan judul artikel, tahun, jurnal/prosiding, DOI, dan URL setelah datanya siap. Email dan tautan profil indeksasi tidak dibuat-buat; dapat ditambahkan kemudian pada bagian kontak.
